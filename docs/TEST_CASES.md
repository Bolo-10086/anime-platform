# 测试用例

| 编号 | 模块 | 测试内容 | 操作步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| TC-01 | 登录 | 管理员登录 | 使用 `admin/admin123` 登录 | 登录成功，显示后台管理菜单 |
| TC-02 | 登录 | 普通用户登录 | 使用 `demo/demo123` 登录 | 登录成功，不显示后台管理菜单 |
| TC-03 | 权限 | 普通用户访问后台接口 | 用 demo Token 请求 `/api/admin/user/list` | 请求失败 |
| TC-04 | 首页 | 查看首页 | 访问 `/home` | 显示推荐动漫、分类、标签、资讯 |
| TC-05 | 动漫库 | 关键词筛选 | 输入动漫名称查询 | 返回匹配作品 |
| TC-06 | 动漫库 | 分类筛选 | 选择主分类 | 返回对应分类作品 |
| TC-07 | 动漫库 | 标签筛选 | 选择标签 | 返回包含该标签的作品 |
| TC-08 | 动漫库 | 组合筛选 | 同时选择分类、年份、类型 | 返回符合条件作品 |
| TC-09 | 动漫详情 | 查看详情 | 点击动漫卡片 | 显示封面、简介、标签、正版入口 |
| TC-10 | 收藏 | 收藏与取消收藏 | 登录后在详情页点击收藏按钮 | 收藏状态正确变化 |
| TC-11 | 评分 | 提交评分 | 登录后选择评分 | 评分保存，作品均分更新 |
| TC-12 | 评论 | 发表评论 | 登录后输入评论并提交 | 评论区新增评论 |
| TC-13 | 个人中心 | 查看互动记录 | 进入 `/profile` | 显示收藏、评分、评论记录 |
| TC-14 | 后台动漫 | 新增/编辑动漫 | 管理员维护动漫资料 | 数据保存成功 |
| TC-15 | 后台分类 | 维护分类 | 管理员新增或编辑分类 | 前台筛选可使用 |
| TC-16 | 后台标签 | 维护标签 | 管理员新增或编辑标签 | 前台标签筛选可使用 |
| TC-17 | 后台评论 | 隐藏评论 | 管理员隐藏评论 | 前台详情页不再显示 |
| TC-18 | 后台用户 | 禁用用户 | 管理员禁用普通用户 | 用户无法继续使用受保护接口 |
| TC-19 | 后台资讯 | 发布资讯 | 管理员新增资讯 | 前台资讯中心可见 |
| TC-20 | 统计看板 | 查看图表 | 管理员进入 `/admin/stats` | 显示分类占比和浏览排行 |
