# 论文和答辩截图清单

## 前台页面

- 首页：轮播推荐、热门动漫、分类入口、标签入口、资讯入口。
- 动漫库：筛选栏和动漫卡片列表。
- 动漫详情：横幅图、封面、基础信息、简介、正版入口、评论、收藏、评分。
- 资讯中心：资讯列表和查询。
- 资讯详情：标题、封面、发布时间、浏览量和正文。
- 登录页和注册页。
- 个人中心：用户资料、收藏记录、评分记录、评论记录。

## 后台页面

- 后台统计看板：数据卡片和 ECharts 图表。
- 动漫管理：列表、新增、编辑弹窗。
- 分类管理：列表、新增、编辑弹窗。
- 标签管理：列表、新增、编辑弹窗。
- 资讯管理：列表、新增、编辑弹窗。
- 评论管理：评论状态切换。
- 用户管理：用户状态切换。
