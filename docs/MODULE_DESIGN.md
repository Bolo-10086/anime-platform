# 功能模块设计说明

## 用户认证与权限模块

用户认证模块负责注册、登录、身份校验和角色权限控制。系统使用 BCrypt 对用户密码加密保存，登录成功后由后端签发 JWT Token。前端保存 Token，并在请求拦截器中自动加入 `Authorization` 请求头。

系统角色分为管理员和普通用户。普通用户可以浏览动漫、评论、收藏、评分；管理员可以进入后台进行动漫、分类、标签、资讯、评论和用户管理。

## 动漫信息模块

动漫信息模块负责展示近十年热门真实动漫作品，包括动漫名称、原名、封面、主分类、标签、地区、年份、类型、状态、集数、评分、简介、正版观看入口和官方预告入口。

前台用户可以通过首页、动漫库和详情页浏览作品。动漫库支持关键词、分类、标签、年份、状态、地区和类型组合筛选。

## 分类与标签模块

分类体系采用“主分类 + 多标签”的方式。主分类用于统计和主要检索，例如动作、奇幻、科幻、悬疑、恋爱、日常、运动、音乐、治愈、冒险、剧场版。

标签用于更细的题材识别，例如战斗、热血、校园、漫画改、轻小说改、原创、异世界、赛博朋克、推理、家庭、成长、催泪等。

## 用户互动模块

登录用户可以对动漫发表评论、收藏动漫和提交评分。评论会显示在动漫详情页；收藏、评分和评论记录会汇总到个人中心。

管理员可以在后台评论管理中隐藏或恢复评论，从而维护前台互动内容质量。

## 资讯模块

资讯模块用于发布平台公告、动漫资讯和内容更新。前台用户可以浏览已发布资讯，管理员可以在后台新增、编辑、删除资讯，并设置发布或草稿状态。

## 后台管理模块

后台管理模块面向管理员，包含统计看板、动漫管理、分类管理、标签管理、资讯管理、评论管理和用户管理。

统计看板使用 ECharts 展示动漫数量、用户数量、评论数量、收藏数量、评分数量、分类占比和浏览排行。
