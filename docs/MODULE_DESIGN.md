# 系统模块设计

## 前台模块

- 首页：展示热门推荐、热门动漫、分类入口、标签入口、资讯入口。
- 动漫库：按关键词、分类、标签、年份、状态、地区、类型筛选动漫。
- 动漫详情：展示封面、横幅图、基础信息、简介、正版入口、预告入口、评论、收藏和评分。
- 资讯中心：展示动漫相关资讯，支持标题和摘要查询。
- 个人中心：展示当前用户资料、收藏记录、评分记录和评论记录。

## 认证与权限模块

- 用户注册和登录采用 JWT。
- 密码使用 BCrypt 加密存储。
- 前端保存 Token 并在请求中自动携带。
- 后台接口校验管理员角色，普通用户不能访问后台管理功能。

## 后台管理模块

- 统计看板：展示动漫、用户、评论、收藏、评分、分类、年份、排行等数据。
- 动漫管理：维护动漫名称、原名、分类、标签、封面、横幅图、简介和正版入口。
- 分类管理：维护主分类，用于筛选和统计。
- 标签管理：维护多标签，用于细粒度题材筛选。
- 资讯管理：维护前台资讯内容。
- 评论管理：管理用户评论显示状态。
- 用户管理：查看用户角色、状态和互动数据，支持启用和禁用账号。

## 数据设计概览

- 用户相关：`sys_user`、`sys_role`、`sys_user_role`
- 动漫相关：`anime_info`、`anime_category`、`anime_tag`
- 互动相关：`anime_comment`、`anime_favorite`、`anime_rating`
- 资讯相关：`news_info`

系统采用“主分类 + 多标签”的内容组织方式，既方便前台筛选，也方便后台统计和论文说明。
