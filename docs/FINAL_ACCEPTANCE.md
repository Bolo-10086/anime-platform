# 最终验收清单

| 项目 | 内容 |
| --- | --- |
| 后端 | SpringBoot、MyBatis Plus、MySQL、JWT |

| 数据库 | MySQL 8 |
| 后端地址 | `http://localhost:8080` |
| 前端地址 | `http://localhost:5173` |
| 管理员账号 | `admin / admin123` |
